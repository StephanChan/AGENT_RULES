# 作业规则（每个任务开始时先读仓库根目录的 README_AGENT_RULES.md）

> 本文件 = 需要自动加载的**硬约束摘要** + **已知事实**。规则完整版见 `README_AGENT_RULES.md`（唯一完整版）；
> 冲突时以完整版为准，本文件只允许比完整版**更严格**。

## 第 0 步（强制，先于任何其它动作）
- **第一个响应**就用**同一次 `read_files` 调用**读 `README_AGENT_RULES.md` 和本文件，同时把本次任务要看的
  代码文件/区间一并读进来——合并成一次调用，**不额外占批次**（"读规则多花一批"从来不是理由）。
- 只认文件**当前文字**：记忆、上下文摘要**不算**，不许拿"我记得"顶替"我读过"；不许等用户提醒。
- **没读 = 严重违规**：停下补读，并复核该响应已发出的改动，与规则冲突就回滚重做。

1. **验证只做 1 次必要的**：改完只做**一次**语法/编译检查，按文件类型选（`.py`→`python -m py_compile`；
   `.js`→`node --check`；`.json`→`ConvertFrom-Json`；非代码文件不跑命令；完整表见 README 第 1 节），通过就回答。
   默认**不做**全量 `run_self_test()`、phantom 重建、多组参数对比、反复渲染图、把结论写成脚本再跑。
   只有用户明确要"证明/给我数字"时才做一次针对性实测，够用就停。
2. **命令越少越好**：每条命令直接回答一个问题，能合并的用 `;` 合并；需要看输出就重定向到文件再
   `read_files`，不要重复跑同一个命令。已知路径直接读，不先列目录。**检索一律走 `search_codebase`**
   （一次传**多个** pattern）/ `read_files`（一次读多个文件/区间），**禁止用 shell 做纯检索**
   （`Select-String`、`Get-ChildItem -Recurse`），不许"没命中→再猜一条"连环 grep。
3. **时间预算**：一轮回答里工具调用 ≤ 2 批（= 1 批"读/改" + 1 批"验证"）；用户说"N 分钟内"→ 只做最小
   改动 + 一次编译/运行，立刻回答。**独立改动必须同一响应批量发出**：不同文件、或同一文件不重叠区域的
   多个 editor 调用放在同一个响应里并行发，禁止一处改动一个响应；markdown/规则文件改完不用跑命令。
   **改前先取锚点（2026-10-07 的教训）**：动手前用一次 `read_files` 把每处锚点的原文**连缩进**读准；
   同一文件里不重叠的多处改动一律在同一个响应并发发 editor（除了"失败重试"，没有"等上一处改完"的正当理由）；
   editor 单次文本 ≤6000 字，超了先写前半、下一响应追加后半（这是唯一允许的串行）。
   **大改动先给计划**：跨文件、超过 3 个文件、或改公共接口/数据格式时，先用 3–5 行说清改哪里再动手。
   **优先级**：用户当前轮的明确指令 > 本文件/README 规则 > 记忆/历史约定（README 第 6 节）。
4. **回答格式**：结论 → 改了哪个文件哪几行 → 怎么用 →（可选）一次验证结果。不复述命令日志、不贴大段已有代码。
   中文回答；用户说"只答是/否"就只答是或否。
5. **参数命名**：只有 `P`（一圈 360° 的像素数）/ `Xc`（轴横坐标）/ `d`（轴到参考点偏移）三个规范名，
   完整定义与旧名别名表见 `README_AGENT_RULES.md` 第 5 节；旧名（`half_turn`/`centre`/`offset`/`axis_px`/
   `guess_px`/`initial_center`/`--center` 等）只允许作为兼容别名出现，新增代码/日志/文档一律用规范名。
6. **安全边界**（摘要）：不删/不覆盖未确认的文件，不整文件重写；不跑 `git push` / `reset --hard` / `clean -fd`；
   装依赖、联网、长任务前先问；密钥不进代码与回答。完整条款见 `README_AGENT_RULES.md` 第 7 节。
7. **不许编造**（摘要）：不确定的库/API/路径/参数先 `search_codebase` 或查文档，不许凭记忆当"已知事实"；
   没跑过的检查不说"已验证通过"。完整条款见第 8 节。
8. **需求有歧义**：真实分叉用一次 `ask_question`（2–5 选项），不猜着做；能确定的事不问许可（第 9 节）。
9. **交付自检**：回答前回读关键行确认落盘、无 TODO/占位符、调用点与文档同步（第 10 节）。
